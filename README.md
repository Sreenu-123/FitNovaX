# 💪 FitNovaX

### Build Your Strength. Own Your Journey.

**FitNovaX** is a fitness and wellness mobile application currently under active development, built with Flutter and powered by a FastAPI backend.

The vision is to create a modern fitness companion that brings workouts, personal fitness tracking, and everyday wellness experiences together in one place.

> 🚧 **STATUS: WORK IN PROGRESS**
>
> FitNovaX is actively being developed. Features, UI, and functionality are subject to change as the project evolves.

---

## ✨ About

FitNovaX aims to make fitness more accessible through a clean interface, personalized experiences, and useful wellness tools.

The project is being built step by step, with a focus on creating a strong foundation for a future fitness platform.

## 🚀 Features

- 🔐 User registration and login
- 👤 Personal profile management
- 🏋️ Workout interface
- 📊 Fitness dashboard and progress overview
- 🥗 Nutrition and weight-tracking interfaces
- 💧 Water-tracking interface
- 🌙 Sleep-tracking interface
- 🔔 Reminders and wellness tools
- 🎨 Dark-themed UI with blue accents

*Some features are still under development and may not be fully functional.*

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Mobile application |
| Dart | Application development |
| FastAPI | Backend API |
| PostgreSQL | Database |
| SQLAlchemy | Database interaction |
